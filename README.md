# Primarch Fashion Battle

Static GitHub Pages project for the HereticDiary primarch tournament.

## Project files

- `index.html` — page structure and section navigation.
- `styles.css` — visual styles and responsive layout.
- `js/tournament.js` — participant data, draw logic, sequential voting, round progression, result history, profiles, and Hall of Fame.

## Notes

- Tournament progress is currently kept in page memory and resets on reload.
- No external libraries or build step are required.
